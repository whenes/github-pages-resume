## Scope

`components.html`: the portfolio design system reference. Foundations (tokens, type, color) plus the "dev components" the portfolio pages are assembled from, each shown live with its copyable HTML. Mode: Operate for the reference shell; the component demos are Experience/Persuade pieces for recruiters.

## Audience and job

Owner assembling portfolio pages (primary here); recruiters and tech leads are the end readers of every component. Content comes only from the resume PDF and public GitHub.

## Constraints

Static HTML/CSS/vanilla JS on GitHub Pages. Steply token names, 4px scale, Inter UI, dark default + `data-theme="light"`. Illustrative code or flag names labeled as such.

## Direction contract

THESIS: a senior engineer's career read as version history, legacy and modern running side by side; refuses the generic hero + skill-bars + project-grid portfolio kit.
OWN-WORLD: Steply night-console surfaces #1e1f22/#2b2d31/#313338, blurple #5865f2 as the single committed accent, Inter UI, Unbounded for short display headings, JetBrains Mono only for code, refs, dates and flags; 6/8px radii, 1px hairline borders, soft offset shadows.
STORY: reader sees who Whenes is, how the consultancy years branch into client projects, what "modernize without breaking" meant in practice, then reaches email/LinkedIn/GitHub/resume.
FIRST VIEWPORT: Steply app shell; 240px sidebar listing components; content opens on the profile header demo at full width: name in Unbounded ~3rem, title, location, contact actions, beside the live git-graph excerpt of SUPERO → TOTVS.
FORM: pinned Steply world, surface-scope structure chosen in thread (no seed: world pinned by user); signature interactions: git-graph career log with expandable commits, feature-flag toggle flipping legacy/modern request path.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
